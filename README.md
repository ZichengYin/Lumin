# 余光

> 全黑画面的音乐节奏游戏 + 视觉小说 + 双结局。
> 零游戏引擎，零第三方依赖，HTML + 原生 JavaScript。

---

## 现在能跑什么

一个**完整的关卡**：一条由角度定义的砖块路径，行星沿着它走，你在每一块砖上按空格。

- 播放一首 120 BPM 的占位音乐（鼓点 + 贝斯 + 和弦，由 `tools/make-placeholder-music.mjs` 现场合成，不下载任何素材）
- 谱面是 `levels/level01.json`：**32 块砖**，每拍一块，画面上是一条起伏的锯齿轨道
- 镜头跟着行星走，走过的轨道会变暗
- 行星的位置每一帧都由音频时钟反算 —— 掉帧、切标签页都不会和音乐漂开
- 轨道上那圈暖色弧线就是 **PERFECT 窗口**，蓝色是 GOOD，白色是 OK
- 按空格 → 报出**角度差多少度、相当于早/晚多少毫秒**，并记连击和准确率
- 漏掉会自动记 MISS；离得太远的按键算「空按」，不消耗砖块也不扣连击

判定用的是「按下那一瞬间」的音频时间，不是「上一帧画在哪」——60fps 下这一条差
16.7ms，120 BPM 时相当于 12°，足够把 PERFECT 判成 GOOD。

### 几何上是怎么接上的

行星绕**当前砖块**转，半径恒为两砖间距的一半。于是**两砖中点恰好落在轨道圆上**，
行星转到中点的那一瞬间就是完美时刻；到达后它立刻改绕下一块砖，因为中点离两块砖
都是半个半径，**切换前后位置严丝合缝，画面上看不到任何跳变**。

每块砖转过多少度、花几拍、和 ADOFAI 是什么关系，见
[判定与轨道模型](docs/03-判定与轨道模型.md)。

## 怎么跑起来

**双击 `启动游戏.bat`**（需要先装 [Node.js](https://nodejs.org) LTS 版）。

它会自动起一个本地服务器并打开浏览器，地址是 <http://127.0.0.1:8123/>。

> ⚠️ **不要直接双击 `index.html`。**
> 这个项目用的是 ES 模块，浏览器在 `file://` 协议下会以跨域为由拦掉模块加载，
> 你会看到一片全黑。必须走一个 http 服务器，`启动游戏.bat` 就是干这个的。

> ⚠️ **`启动游戏.bat` 里不要写中文，一个非 ASCII 字节都不行。**
> cmd.exe 读取批处理时是按字节偏移、并且用当前代码页解释的。文件里有 UTF-8 中文时，
> 解析器会丢失对齐，吃掉字符、甚至把相邻两行合并成一条命令——
> 结果可能是 `echo` 变成 `cho`，也可能是 `node tools\serve.mjs` 被拆成 `tools\serve.mjs`，
> 于是 Windows 拿这个文件去找关联程序，你就看到源码在浏览器里打开了。
> 所有面向玩家的中文提示都由 `tools/serve.mjs` 打印（Node 写 UTF-8 没问题）。

命令行方式：

```bash
npm run dev          # 起服务器，默认 8123 端口
npm run dev -- --port 9000 --no-open
npm test             # 跑全部单元测试（当前 86 个）
```

改谱面（**改完先跑预览器，比开浏览器快得多**）：

```bash
node tools/preview-chart.mjs levels/level01.json
```

重新生成占位音乐（想做别的 BPM 就改参数）：

```bash
node tools/make-placeholder-music.mjs --bpm 140 --bars 24 --out assets/audio/placeholder-140bpm.wav
```

换曲子时要同步改 [`src/config.js`](src/config.js) 的 `audio.url`，以及**谱面文件里的 `bpm`**——
`npm test` 里有一条会去量音频重拍的实际位置，对不上就直接失败。

谱面格式的完整说明见 [谱面格式](docs/04-谱面格式.md)。

## 操作

| 按键 | 作用 |
| --- | --- |
| `空格` / 鼠标点击 | 开始 · 判定 · 结束后重来 |
| `←` `→` | 调整音频偏移（±5 ms） |
| `Shift` + `←` `→` | 微调偏移（±1 ms） |
| `R` | 从头重来 |

> **偏移是干什么的。** 浏览器把音频交给系统、系统再送到耳机，这中间有几十毫秒。
> `←→` 调的就是这个补偿，让你按的时机对上**你耳朵听到的**声音，而不是浏览器以为的时间。
> 总是判「晚」就往右调，总是判「早」就往左调。
>
> 默认值取自 `AudioContext.outputLatency`（通常在 5～30ms），一般已经接近，
> 但没有任何自动值能替代你自己听一遍。

浏览器控制台会同步打印每次判定的结果（第几拍、角度差、早/晚多少毫秒），方便对数值。

## 调手感

不用改代码，URL 参数就能试：

```
http://127.0.0.1:8123/?chart=levels/level01.json&r=0.12&offset=-10
```

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `chart` | 谱面文件路径 | `levels/level01.json` |
| `r` | 轨道半径 = `min(宽,高) × r`（越小视野越广） | `0.145` |
| `offset` | 手动音频偏移（毫秒），叠加在硬件延迟之上 | `0` |

判定窗口、配色、镜头跟随速度等所有常量都在 [`src/config.js`](src/config.js) 里，
改完刷新即可。BPM、路径形状、节奏则全在谱面 JSON 里。

## 美术方向

`动画/` 里的素材定下了**黑白网点 / 噪点漫画风**：高对比、阴影用网点堆、铅笔速写线条。

所以「全黑画面」拆成两层：

- **音游层** — 纯黑，只有轨道、砖块、行星、判定文字。不多加任何一个像素。
- **视觉小说层** — 黑白漫画，用 `动画/` 那种质感的立绘和背景。

细节见 [`docs/01-技术方案.md`](docs/01-技术方案.md) 最后一节。
